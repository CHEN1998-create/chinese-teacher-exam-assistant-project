# 教招有据 · 模块 2：招募筛选题（10—15 人人工验证）

- 版本：v1.0（2026-10-06）
- 用途：从【招募渠道】筛选「考虑报考语文教师、**目标批次或资格未完全确定**」的受访者
- 目标样本：**10—15 人**完成首访；其中 **5—8 人**纳入「官方资格保证误认测试」
- 配套：[知情说明与同意书](./教招有据-模块2-知情说明与同意书.md)、[访谈脚本](./教招有据-模块2-访谈脚本.md)、[工具包总说明](./教招有据-模块2-人工验证工具包.md)

> 招募渠道、补偿标准、研究者联系方式为**待产品负责人确认项**（见 v2 计划「需负责人确认」），本问卷中以 `【待确认】` 标注，启用前必须填实，不得用虚构渠道招募。

---

## 一、硬性入选条件（全部满足才入组）

1. 未来 12 个月内**认真考虑**报考中小学语文教师岗位（含应届、在职、社会人员）。
2. 当前处于「不确定」状态，满足以下至少一项：
   - 还没确定报考哪个地区/批次；
   - 不确定自己的学历/专业/教资/户籍/年龄等条件能报哪些岗；
   - 知道大概方向但没开始系统关注公告。
3. 本人完成报名决策（非代亲友打听；可接受家长陪同，但受访者须为报考本人）。
4. 有可日常使用的智能手机/微信，能配合连续 **7 天**跟进。
5. 同意匿名化记录与访谈录音（仅研究用，见知情说明）。

## 二、排除条件（命中任一项不入组）

1. 已有明确目标岗位且**已完成报名**（不属于「未完全确定」人群；可入备选库，不进本轮）。
2. 报考意向非语文（本轮只验证语文）。
3. 培训机构从业者、竞品研究者、人力资源服务商（避免利益相关）。
4. 无法用普通话完成 30—45 分钟访谈。

## 三、配额建议（招募时主动平衡，避免样本同质）

| 维度 | 建议配额（以 12 人为例） |
| --- | --- |
| 身份 | 应届在校生 4—5 / 已毕业待业或在职 5—6 / 在职教师考虑跳槽 1—2 |
| 学历 | 本科 7—8 / 研究生 4—5 |
| 教师资格 | 已取得 4—5 / 合格证明或在考 4—5 / 暂无但符合「聘用前取得」情形 2—3 |
| 目标地区 | 杭州/宁波（首批监测区）6—8；浙江省内其他或长三角 4—6 |
| 误认测试子样本 | 从入组者中取 **5—8 人**，尽量覆盖不同学历/身份，不要全选应届生 |

> 当前杭州/宁波监测事实（2026-10-06）：**0 个在报语文批次**，下一窗口预计 11—12 月提前批。允许受访者目标地区超出首批监测区，但超出部分的候选岗位须由研究者**人工检索官方来源**并计入岗位维护人时；若无法凑齐 3 个候选，**如实记录**，不降格用转载站/培训机构汇总信息充数。

## 四、筛选问卷（逐题照读，答案记入逐人记录表）

### A. 意向与确定性（甄别核心）

A1. 你是否在考虑报考中小学语文教师岗位？
　□ 是，正在看机会　□ 是，有想法还没开始看　□ 不确定要不要考　□ 否（→ 终止）

A2. 你现在对「报哪个地区、哪一批」的确定程度？（1—5 分）
　1 完全没方向　2 有大概地区没定批次　3 定了地区在等批次　4 已锁定具体公告　5 已报名
　→ 选 4/5 且 A3 也确定者，按排除条件 1 处理（致谢终止或入备选库）。

A3. 你对自己「符不符合报名条件」的确定程度？（1—5 分）
　1 完全不清楚自己能报什么　2 知道几项但不确定够不够　3 大体清楚但有疑点　4 基本确定　5 非常确定
　→ 入组优先选 1—3 分者；4—5 分者若 A2 ≤3 仍可入组，但配额不超过 2 人。
