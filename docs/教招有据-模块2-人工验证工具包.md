## 二、角色与分工建议

| 角色 | 人数建议 | 职责 |
| --- | --- | --- |
| 主访人 | 1 | 筛选、访谈、复述判定，填逐人记录表 |
| 岗位维护人 | 1（可与主访人同人，但人时分开记） | 按模块 1 SOP 人工检索/核对候选官方来源，填岗位候选表，记准备与维护人时 |
| 跟进人 | 1 | Day1—7 接触、催收动作记录、登记未行动原因 |
| 复核人 | 1 | 每天抽查 ≥20% 候选行的官方链接与字段；误判当场更正并在错误台账归因 |

## 三、执行节奏（首访 + 7 日，全程 ≥8 个自然日）

1. **D-3 ~ D-1 招募与筛选**：按筛选题执行；满足全部硬性条件才入组；按配额主动平衡样本。
2. **D-1 候选准备**：岗位维护人为每人准备 3—8 个候选并填岗位候选表；复核人抽查后才能带去访谈。
   - 候选必须全部可追到**政府官网原文 + 岗位表附件行**；转载/机构汇总一律不用。
   - **不足 3 个就如实写「实给 X 个」并注明原因**（如目标地区当前确无在报语文岗），不凑数、不用历史批次冒充在报。
3. **D0 首访**：知情同意 → 背景 → 候选讲读 → **无提示复述** → 可信度核对 →（子样本）误认测试 → 7 日约定。
4. **D1—D7 跟进**：每日一次轻接触；动作分类固定为**关注 / 补资料 / 官方咨询 / 材料准备 / 进入官方报名入口 / 已报名 / 未行动（必须记原因）**；无回复次日补问一次，仍无回复记「失联」并保留已记录部分。
5. **D7 末轮追访（可选 5 分钟）**：对零动作者问原因；对有误认/误解者复核其最终理解。
6. **D8 复盘**：汇总四张表，按第六节出判断；**样本/供给不足时如实写「不足以支持结论」**。

## 四、统一口径（与模块 1 完全一致，访谈中不得走样）

1. **四分清**：官方事实 / 系统推断 / 用户确认 / 未知，必须分开呈现；缺信息 ≠ 不符合；「暂未收录」≠ 当地无招聘。
2. **四档结论**：初步符合 / 补充信息后判断 / 建议人工确认 / 明确不符合。
   - 「初步符合」的门槛继承模块 1：高影响字段（学历、专业、毕业状态、教师资格、年龄）全部有官方锚点且经人工复核；AI 初核未复核记录**只可作为展示样本，不得口头当作可报推荐**。
3. **非推荐可信状态**：预告（报名时间待官方通知）/ 已截止 / 来源失效 / 暂未收录。
4. **用工性质**只引用公告原文（事业编制/备案制/员额制/聘用合同制等），不做跨公告推断。
5. **当前供给事实（2026-10-06 核对）**：杭州、宁波 0 个在报语文批次；向受访者展示时如实说明「监测就绪、当前 0 在报、下一窗口预计 11—12 月」。
6. 所有「咨询结果」是**用户自行记录的信息**，未经官方公告确认不得变成系统事实。

## 五、关键指标与判定阈值（建议值；复盘时先复核阈值本身是否合理）

### 5.1 样本有效性门槛（达不到则只描述、不下比例结论）

- 首访完成 ≥10 人；每人 7 日跟进有回复天数 ≥5 天（记为「有效跟进」）；有效跟进 ≥8 人。
- 误认测试子样本 ≥5 人；少于 5 人只报个案，不报误认率。

### 5.2 理解与信任指标

| 指标 | 计算 | 建议阈值 |
| --- | --- | --- |
| 依据可复述率 | 复述判定「通过」人数 / 首访完成人数 | ≥80% 视为基本达标 |
| 不确定项可复述率 | 说出 ≥1 个自身待确认点人数 / 首访完成人数 | ≥80% |
| **官方保证误认率** | 「明确误认」人数 / 受测人数 | **红线：≥2 人或 ≥25% → 立即停止扩量，先修信任表达（模块 0/5），修复后重测** |
| 部分误认 | — | 任一例都要登记并给出文案/层级修改建议 |
| 缺信息误判为不符合 | 发生人次 | **高严重度零容忍**：任 1 例即列为数据/规则侧待修项 |

### 5.3 行为指标（7 日窗口）

- 分类计数：关注、补资料、官方咨询、材料准备、进入官方报名入口、已报名的**去重人数**（重复动作不重复计）。
- 零行动率与零行动原因结构（供给为 0 导致 / 个人时间 / 不信任 / 不会操作 / 在等预告）——**先归因，再谈比例**。
- 注意当前 0 在报窗口：「已报名/进入官方入口」预期为 0 属正常，不得为追求动作量诱导用户报名已截止批次。

### 5.4 数据/规则质量（来自错误台账）

- 高严重度：官方依据错误、岗位表行错配、公告状态与官网不一致、高影响字段无锚点却展示为确定。
- **高严重度 >2 条或任 1 条影响到用户行动 → 先修数据/规则（模块 1/5），再谈扩大人群。**

### 5.5 人时指标

- 逐人汇总：岗位准备人时、访谈人时、跟进人时；换算「**每提供 1 个可追溯候选的人时**」与「**每人 7 日维护人时**」，作为供给可持续性判断依据。

## 六、复盘判断框架（三选一，只能基于真实记录）

| 判断 | 触发条件（需同时满足主条件） | 下一步 |
| --- | --- | --- |
| **A. 继续改造核心流程** | 误认率低于红线；依据/不确定项复述率 ≥80%；错误以交互层级、找不到入口、提醒缺失为主 | 带着证据进入模块 3（导航）与模块 5（详情层级） |
| **B. 先修数据/规则** | 出现高严重度数据/规则错误，或「缺信息被当不符合」，或初步符合里混入未复核记录 | 回模块 1 补复核、修闸门与证据层级，重测受影响样本人群后再推进 |
| **C. 收缩人群/地区/时机** | 筛选通过率 <40% 且原因是人群画不上；或入组者在当前窗口普遍无岗可跟（供给问题而非产品问题）；或目标人群对四档表达普遍无法理解 | 收缩到批次窗口期、杭州/宁波以外有在报批次的地区，或更明确的应届/在职细分；明确写出收缩理由与再放开条件 |

- 三个判断可以带附加条件组合（如「A，但必须先完成 B 的 2 项高严重度修复」），但**不允许在样本不足时强行给结论**。
- 判断必须引用台账中的编号证据（P0x + 候选序号/台账行）。

## 七、复盘报告模板（真实数据回来前保持空白，不得预填）

1. **执行概况**：渠道、筛选通过/排除人数与原因、入组 N、有效跟进 N、误认子样本 N、实际日期窗口。
2. **供给事实**：实发候选总数、人均候选数、不足 3 个的人数与原因、在报/预告/已截止构成。
3. **理解与信任**：依据复述、不确定项复述、误认判定逐人结果 + 原话证据编号。
4. **7 日行为**：七类动作去重人数；零行动原因结构；官方咨询/报名等关键动作的官方出口核实情况。
5. **错误台账汇总**：按类型 × 严重度 × 归因计数；高严重度逐条列出与处置状态。
6. **人时**：每候选人时、每人 7 日维护人时、复核人时。
7. **判断**：A/B/C（或带条件组合）+ 台账证据编号 + 具体修复清单（指向模块 0/1/3…7）。
8. **局限**：样本偏差、0 在报窗口影响、失联、研究者偏差（如主访人无意引导）。
