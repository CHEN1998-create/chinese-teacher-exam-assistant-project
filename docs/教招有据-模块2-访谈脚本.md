# 教招有据 · 模块 2：访谈脚本（含官方保证误认测试）

- 版本：v1.0（2026-10-06）
- 时长：30—45 分钟；方式：线上共享屏幕或线下面对面（建议手机端展示，贴近真实使用）
- 对象：每名入组受访者（P01…）；**第三部分 E 段「官方保证误认测试」仅对 5—8 人子样本执行**
- 配套：[知情说明](./教招有据-模块2-知情说明与同意书.md)、[逐人记录表](./教招有据-模块2-逐人记录表.csv)、[岗位候选表](./教招有据-模块2-岗位候选表.csv)、[行为与错误台账](./教招有据-模块2-行为与错误台账.csv)

> **主访人纪律（务必遵守）**
> 1. 全程只问开放问题，不用「是不是官方的」「这个意思是你符合对吧」等**是非/引导式**提问。
> 2. 在受访者完成复述前，**不解释、不纠正、不解释四档含义**——复述必须「无提示」。
> 3. 不承诺任何岗位可报、可过；受访者直接追问「那你说我能不能报」时，统一话术：「这个最终要以官方公告和招聘单位审核为准，我们先看公告原文怎么写。」
> 4. 所有结论必须能点开官方原文/岗位表附件；准备好的候选若访谈时发现链接失效，**当场标记来源失效**，不换用转载内容。

---

## 第零部分：访谈前准备（研究者，不在访谈中进行）

1. 依据筛选问卷 B/C 部分，为该受访者准备 **3—8 个候选岗位**，全部来自政府官网公告：
   - 优先使用模块 1 台账（杭州/宁波已核公告）；目标地区超出监测区时，人工检索该区教育局/人社局/人民政府官网，**禁用培训机构汇总、自媒体转载**作为依据。
   - 每个候选填入[岗位候选表](./教招有据-模块2-岗位候选表.csv)：官方原文 URL、岗位表附件名/序号行/下载 URL、关键资格、四档初判、依据摘录、**缺项**、下一步、核对时间、准备耗时（人时）。
2. 状态集合（向受访者展示时必须如实，不要凑数）：
   - 四档结论：**初步符合 / 补充信息后判断 / 建议人工确认 / 明确不符合**；
   - 不属于四档结论的可信状态：**报名预告（时间未定）/ 已截止 / 来源失效 / 暂未收录**。
   - 当前（2026-10-06）杭州、宁波 0 个在报语文批次：若候选人目标仅限该两地，大概率出现「已截止 + 预告」组合，**这是真实结果，照实展示**；不足 3 个候选时在岗位候选表「备注」写明「官方在报岗位不足，实给 X 个」。
3. 准备展示物料：候选卡片（可用产品截图/原型/纸质卡片，内容必须与岗位候选表一致）、官方网页（提前打开备用，但让受访者看到 URL 栏）。
4. 误认测试子样本额外准备：「教招有据」产品页（机会列表 + 一张「初步符合」卡片 + 详情页，含模块 0/1 已上线的预筛声明与官方依据区）。

## 第一部分：开场与知情（约 5 分钟）

1. 自我介绍，按[知情说明](./教招有据-模块2-知情说明与同意书.md)逐条说明，完成同意项勾选与签名。
2. 说明访谈方式：「今天没有标准答案，我想知道你真实的看法。你说看不懂、觉得奇怪，对我们反而最有用。」
3. 确认录音。

## 第二部分：背景与报考处境（约 8 分钟）

1. 「先聊聊你现在考语文老师这件事——你是怎么考虑的？」（听其自然叙述，追问目标地区、批次、时间预期）
2. 「你平时从哪里看招聘信息？」「有没有看到过让你拿不准、不知道信不信的信息？」
3. 对照筛选问卷快速确认画像（学历、专业、教资、普通话、户籍、年龄），有出入**当场更正**候选准备。
4. 「事业编、备案制这些说法你分得清吗？」（记录理解水平，不展开科普，留到看卡片时观察）

## 第三部分：候选岗位判读（核心环节，约 18—25 分钟）

### A. 浏览与第一反应（3—5 分钟）

展示全部候选卡片（不先给任何解释），说：
> 「这是我们按你的情况整理的几个真实招聘岗位。你先从上到下看一遍，想到什么说什么。」

观察并记录：先看哪里、停留在哪、点不点依据链接、对状态标签的第一反应、是否发现「已截止/预告」。

### B. 逐张卡片讲读（8—12 分钟）

每次一张，按「**状态 → 依据 → 缺项 → 下一步**」顺序，让受访者先说，研究者后补：

1. 「这个岗位给你的状态是『＿＿』，你怎么理解这个说法？」
2. 「它凭什么这么判？」——请受访者自己在卡片/详情页上指出依据位置；找不到时再提示官方原文链接与岗位表附件行。
3. 展开**官方原文/岗位表**：一起核对 URL 为政府域名、专业/学历/教资/年龄/户籍等条件原文，用工性质（事业编制/备案制/员额制/聘用合同制）以公告原文表述为准并解释「我们没有自行推断编制」。
4. 「这里有没有跟你有关、但还没法确定的地方？」（对应**缺项**：如教资尚未取得、户籍待核、年龄临界等）
5. 「如果要继续，下一步该做什么？」（对应**下一步**：补信息 / 按公告电话官方咨询 / 准备材料 / 到官方报名入口 / 等预告通知）
6. 每个候选结束前问：「这个结果你信几分？什么情况下你会不信它？」

### C. 无提示复述任务（必做，约 3—5 分钟）

从该受访者候选中挑 **1 个非「初步符合」档**（优先「补充信息后判断」或「建议人工确认」），收起说明文字，只留卡片，说：

> 「现在请你用自己的话跟我说一下：**为什么这个岗位是这个状态？你判断的依据是什么？**另外，**你自己还有哪些地方是不确定的？**」

**禁止插话提示。** 逐字记入逐人记录表两栏：
- 复述的**依据**（是否说到官方来源/具体条件，如「它公告里写了要专业对口」→ 通过；只说「系统说我符合」→ 不通过）；
- 复述的**不确定项**（能否说出至少 1 个自己的缺项或待确认点）。

判定：
| 判定 | 依据复述 | 不确定项复述 |
| --- | --- | --- |
| 通过 | 明确提到依据来自官方公告/岗位表，或引用了具体条件原文 | 说出 ≥1 个与自身相关的待确认点 |
| 部分 | 只复述结论或笼统说「你们查过」 | 只说「没什么不确定」或答非所问 |
| 不通过 | 「系统/软件说的」「它显示我符合」，说不出任何来源 | 把不确定说成没有/拒绝思考 |

### D. 依据可信度核对（约 2 分钟）

1. 「这些信息里，哪条你会自己再去官网核实？为什么是这条？」
2. 「如果卡片写的和教育局公告不一样，你会信哪个？你会怎么发现不一样？」
3. 「『暂未收录』『来源失效』这种状态，你觉得是这个岗位不存在了吗？」（检查是否把缺信息/来源问题误读为「不符合/无招聘」）

### E. 官方保证误认测试（仅 5—8 人子样本，约 5 分钟）

**目的**：检验「教招有据」的展示是否让人误以为它代表官方、或其结论是资格保证。**全程不主动说「预筛」「非官方」「免责声明」**（知情同意环节已做的总说明不算本环节提示），让受访者在最小提示下看真实产品页面。

步骤：
1. 展示产品机会列表页 → 一张「初步符合」卡片 → 详情页（自然浏览，不指点声明文案）。
2. 依次问（开放问法，记录原话）：
   - 「这个页面上的结论，你觉得**是谁给出的**？」
   - 「做这个东西的，和发布公告的教育局，**你觉得是什么关系**？」
   - 「它说你『初步符合』，这意味着什么？**拿着这个，能干嘛、不能干嘛？**」
   - 「如果就差这一步，你觉得还需不需要跟招聘单位确认？为什么？」
   - 「报名是在这里报吗？」
3. 浏览结束后再让其自己找页面上的边界声明（首页/登录页预筛声明、卡片「AI 初核待复核」、官方依据区），问：「这些字你之前注意到了吗？看了之后看法有变化吗？」

**误认判定（逐人只判一个总判定，证据写原话）**：
- ✅ **未误认**：自发说出这是第三方/商业工具的参考整理，结论仅供参考，要以官方公告和单位审核为准，报名得去官方入口。
- ⚠️ **部分误认**：知道不是官方，但把「初步符合」理解成「基本稳了/审核会过」，或认为不需要再向单位确认。
- ❌ **明确误认**：认为这是官方/官方授权渠道，或认为该结论等于资格保证、可据此报名/必过。

> 出现 ❌ 即记入[行为与错误台账](./教招有据-模块2-行为与错误台账.csv)（类型＝官方保证误认，严重度高），访谈尾声按知情口径澄清（见第五部分），但**澄清发生在判定之后**。

## 第四部分：7 日跟进约定（约 3 分钟）

1. 说明每天会收到一次简短问候，用选项 + 语音/文字回复即可，动作分类固定为：
   **关注机会 / 补充自己资料 / 官方咨询（公告电话/官网）/ 材料准备 / 进入官方报名入口 / 已报名 / 今天没行动（原因）**。
2. 「哪怕没行动也请回一句原因——没行动的原因和行动一样重要。」
3. 约定联系时间窗与回复方式，确认补偿口径（知情书中的【待确认】须已填实）。

## 第五部分：收尾（约 2 分钟）

1. 「今天整个看下来，最让你放心的是什么？最让你担心的是什么？」
2. 【误认测试对象或出现误解者必须执行】澄清话术：
   > 「最后再明确一次：我们不是官方机构，今天所有状态都是按公告字面条件做的**预筛参考**，不是资格保证；真正的资格审核由招聘单位做，报名只能走公告里的官方入口。有任何变化以官方最新公告为准。」
3. 致谢，说明后续 7 日安排；不得引导受访者做出「产品很好」式评价。

## 附：主访人现场速记要点（对应台账字段）

- 每个候选：受访者是否自行点开官方链接、是否读岗位表行、对四档措辞的原话反应。
- 错误信号（即时入台账）：把「缺信息」说成「我不符合」；把「预告/已截止」理解成「岗位取消」；把「初步符合」当「保证通过」；混淆编制/备案制；忽略核对时间。
- 人时：研究者为该人准备候选与现场查证的分钟数，访谈结束即填，不靠回忆补。
